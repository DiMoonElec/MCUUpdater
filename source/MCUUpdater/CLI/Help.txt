Синтаксис:
MCUUpdater [-w 60] [-h] [-v] update -f <filename> <transport> [transport-options]

Глобальные опции:
  -w <sec>      Максимальное время ожидания появления устройства (по умолчанию 60 секунд)
  -h            Показать справку
  -v            Расширенный (отладочный) вывод
Команда:
  update -f <filename>.xbin  — Обновление прошивки из указанного файла
Варианты transport:
    serial -p <COMx> [-b 115200] [-r 2]
    raw-tcp -H <host> [-p 5000] [-t 2] [-r 2]

Тайм-ауты (семантика):
  -w, --wait

Глобальный тайм-аут ожидания появления устройства и начала обновления
  -t, --connect-timeout

Тайм-аут одной попытки установления сетевого соединения (TCP)
  -r, --response-timeout

Тайм-аут ожидания ответа устройства на запрос
(присутствует у всех транспортов, необязательный, по умолчанию 2 секунды)

Примеры:

MCUUpdater update -f fw.xbin serial -p COM7
MCUUpdater -w 120 update -f fw.xbin modbus-tcp -H 192.168.1.10 -p 502 -t 2 -r 3
MCUUpdater update -f fw.xbin raw-udp -H 10.0.0.5 -p 7777 -r 1
